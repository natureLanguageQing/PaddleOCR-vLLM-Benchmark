# PaddleOCR-vLLM-Benchmark

本仓库包含了针对 **PaddleOCR-VL 1.5** (0.9B) 在 **vLLM** 推理后端下的性能压测脚本和测试数据集。

[English](./README.md) | 简体中文

---

## 🖥️ 压测环境与显卡配置

- **显卡 (GPU)**: NVIDIA GeForce RTX 4090 (24GB 显存)
- **CUDA 版本**: 13.2 / 驱动版本 596.36
- **测试模型**: PaddleOCR-VL-1.5-0.9B
- **推理框架**: vLLM 本地服务化部署 (OpenAI 兼容接口, `temperature=0`)

---

## 📊 核心性能指标

以下是在 RTX 4090 显卡上，使用高清高考数学试卷图像（单次推理约输出 553 个 Token）运行并发测试的汇总指标：

| 测试场景 | 总请求数 | 瞬间并发数 | 平均端到端延迟 | 吞吐量 (RPS) | 压测结果 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **基准并发** | 20 | 8 | 1.57 秒 | 4.33 RPS | 通过 |
| **超大 Payload (10.5MB 噪点图)** | 16 | 4 | 1.30 秒 | 2.89 RPS | 通过 |
| **高并发压力** | 64 | 32 | 2.80 秒 | **10.57 RPS** | 通过 |
| **变态级极限高压** | 128 | 64 | 3.19 秒 | **18.22 RPS** | 通过 |
